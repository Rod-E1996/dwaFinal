# Tailwind Dashboard

Tailwind Dashboard is a responsive, lightweight, and customizable dashboard template built with Vue 3, Tailwind CSS, and Vite.

## Getting Started

To get started with Tailwind Dashboard, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/Rod-E1996/dwaFinal.git
```

2. Navigate to the project directory:

```bash
cd dwaFinal
```

3. Install the dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and navigate to `http://localhost:5173/` to view the dashboard.
